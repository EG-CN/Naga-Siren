# Naga Siren · 小娜迦

Google Chromecast 遥控器的 macOS 语音输入与按键映射工具。当前版本 **0.9.7（本机测试版）**。

## 功能

- 遥控器麦克风解码，将声音通过虚拟音频设备交给豆包输入法。
- 平时豆包直接使用电脑内置麦克风；遥控器录音期间切换到 MiRemoteV 2ch，结束后恢复。
- 保留豆包原生右 Command 长按语音和右 Option 免按语音。
- 单击、双击、长按映射，方案管理及实体按键检测。
- 菜单栏、自动连接、登录启动、提示音和录音浮条。
- 原生玻璃窗口及可点击遥控器示意图。
- 临时本地诊断日志：不保存声音或识别文字，不自动上传，最多2 MiB。

## 当前验证范围

仅验证 Apple Silicon MacBook Air、一款 Google Chromecast Remote、豆包输入法及 MiRemoteV 2ch。本项目仍是小范围测试版本。

电脑 → 遥控器 → 电脑交替输入曾由用户实测通过；最近的视觉版本未重新执行完整的所有实体按键和语音验收。电脑和遥控器应交替录音，不支持重叠识别。

当前麦克风匹配逻辑使用 MacBook Air 名称；其他机型需要适配。正常结束、暂停和退出会尝试恢复内置输入，强制退出或崩溃无法保证立即恢复。豆包设备切换依赖辅助功能访问其设置页面，豆包更新可能需要适配。

## 使用前准备

1. macOS 14+、Apple Silicon；玻璃效果由系统版本和辅助功能设置决定。
2. 自行安装豆包输入法及兼容的 MiRemoteV 2ch 虚拟音频设备。本仓库不分发驱动和豆包安装包。
3. 在系统蓝牙设置中配对兼容遥控器，在小娜迦中连接。
4. 允许辅助功能；遥控器普通按键映射需要输入监控。电脑麦克风测试需要麦克风权限，Apple 本机备用识别需要额外语音识别权限。
5. 确认豆包长按快捷键与小娜迦用于触发遥控器语音的快捷键一致（默认右 Command）。

## 隐私

遥控器音频在内存中处理并交给豆包输入法，识别服务的数据处理以豆包政策为准。诊断日志仅保存在本机，不保存音频或识别文字，不自动上传。

## 构建

安装包含 Swift 6 的 Xcode 工具链后运行：

```sh
NAGA_SIGNING_IDENTITY='你的代码签名身份' ./build.sh
```

构建者自行准备代码签名身份。本仓库不包含作者的证书或私钥，不自动降级到临时签名。保持更新使用同一签名身份有助于保留系统权限。产物位于 `dist/`，此测试版未经 Apple 公证。
